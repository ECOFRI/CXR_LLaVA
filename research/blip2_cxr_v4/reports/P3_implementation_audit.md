The estimates use FP32 trainable parameter + gradient + Adam moments = **16 bytes/parameter** and the local X02 inference memory as a starting point, not a measured training baseline. ViT/OPT FP16 frozen weights are already included in the X02 peak. Activation intervals are deliberately coarse; actual training memory and time require a separately approved GPU smoke. The synthetic bridge test uses small randomly initialized CPU tensors and does not instantiate OPT or ViT. X08/X09 dry-runs also complete synthetic bridge shape checks before reporting their feature-adapter blocker.

**Data contract.** `src/vlm_medical/data/manifests.py` uses the official `mimic-cxr-2.0.0-split.csv.gz` and metadata files configured in `configs/eval/mimic_p1.yaml` (paths documented in `reports/P1_mimic_audit.md:7-9`). It selects one AP/PA image per study with an existing report and nonempty findings or impression, preserving official train/validate/test patient separation (`manifests/mimic_official_coverage.json`). Indiana X00's saved frontal cohort is an external test only; no Indiana training data are used, so no Indiana exclusion is needed. Existing MIMIC exposure for CXR-LLaVA and possible exposure for other pretrained encoders means MIMIC results require a contamination caveat; exact BLIP-2/CLEAR pretraining overlap remains UNKNOWN. Dry-run checks one eligible study per MIMIC split and X00 cohort file existence; it does not count all eligible training rows or validate model quality. The research data license and permitted use remain binding.

**Code contract.** `scripts/train/train_blip2_bridges.py` accepts `--config`, `--dry-run`/`--train`, `--output-dir`, `--seed`, and `--resume`. `--train` first requires `approvals/<experiment_id>.yaml`; no such approval files were created. The CLI performs CPU dry-run before loading weights on an authorized train request, then checks free GPU memory (8.0 GiB projection; 11.5 GiB Q-Former/LoRA, which intentionally blocks those arms on a single 11.17 GiB K80 until a revised memory plan exists). Checkpoint saving keeps trainable tensors and optimizer state. `scripts/experiments/infer_blip2_bridge.py` accepts a future local trained checkpoint and limits evaluation to official MIMIC test or Indiana X00 external cohort; its CPU dry-run passed, but no trained checkpoint exists and no inference was run. Existing `src/vlm_medical/eval/` remains the evaluator; no new inference result or benchmark was produced. X08/X09 feature adapters are pending source-level tensor verification, so the current train entrypoint refuses those arms. X03/X04/X05/X07 are deliberately minimal JSON-in-YAML skeletons.
